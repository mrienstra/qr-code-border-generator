# CLI Replay: Reproducing Browser Bugs from the Command Line

The `generate()` function is pure — it takes `(svgText, options)` and returns
an SVG string. The replay system captures those exact inputs as a JSON fixture
in the browser so you can re-run the same call from Node without any UI.

## Quick start

1. Open `index.html` in a browser and configure the settings that trigger
   the bug.
2. Click **Copy repro JSON** (next to "Download SVG"). This copies a JSON
   fixture containing the raw QR SVG and the full options object to your
   clipboard. If clipboard access is blocked, a `repro.json` file is
   downloaded instead.
3. Save the JSON to a file (e.g. `bug.json`).
4. Run from the CLI:

```sh
node generate_border.mjs --replay bug.json
```

The output SVG is written to `qr-code-generated.svg` by default. Use `-o` to
change it:

```sh
node generate_border.mjs --replay bug.json -o bug-output.svg
```

## What's in the fixture

The JSON has two keys:

```json
{
  "svgText": "<svg xmlns=\"http://www.w3.org/2000/svg\" ...>...</svg>",
  "options": {
    "colorful": false,
    "circleRatio": 0.82,
    "strokeWidth": 2,
    "bgColor": "#ffffff",
    "roundedPixels": 0.3,
    ...
  }
}
```

- **svgText** — the raw QR code SVG (either generated by qrcodegen.js or
  uploaded). This is the first argument to `generate()`.
- **options** — the full options object, exactly as the browser assembled it.
  Every numeric value is already parsed; no string-to-number conversion
  happens during replay.

## Why not just add more CLI flags?

The existing CLI flags cover a subset of what the browser exposes. At the time
of writing, these browser options have no CLI flag equivalent:

- `obfuscate` (and its sub-fields `amounts`, `darkOnly`)
- `roundedPixels`, `roundedInner`
- `connectDiagonals`, `diagOnly`
- `jiggle`
- `fullLCorners`, `skipCheckerLCorners`
- `contourMode`
- `wobbleFreq`, `wobbleOctaves`, `wobbleScale`

More importantly, flag parsing involves string-to-number conversions that can
introduce subtle differences from what the browser computed. The fixture
approach guarantees byte-identical inputs.

## Console access

The inputs are also available on `window._lastGenerateInputs` after every
redraw, so you can inspect or copy them from the browser console:

```js
// Copy to clipboard from console
copy(JSON.stringify(_lastGenerateInputs, null, 2))

// Or just inspect
console.log(_lastGenerateInputs.options)
```

## Implementation details

Three changes were made:

1. **index.html `redraw()`** — the options object is built into a local
   variable and stored on `window._lastGenerateInputs` before being passed to
   `generate()`.

2. **index.html UI** — a "Copy repro JSON" button was added next to "Download
   SVG". It uses `navigator.clipboard.writeText()` with a fallback to
   downloading a file.

3. **generate_border.mjs `cli()`** — a `--replay <file>` flag was added.
   When present, it reads the JSON fixture, deserializes `svgText` and
   `options`, and calls `generate(svgText, options)` directly, bypassing all
   other flag parsing.
